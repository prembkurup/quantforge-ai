Chapter 2 – Software Requirements Specification

2.1 Purpose
The purpose of this document is to define all functional and non-functional requirements for QuantForge
AI.
This document serves as the primary reference for:
System Architecture
Database Design
API Development
Module Development
Testing
Deployment
Future Enhancements
Every feature implemented in QuantForge AI must be traceable to one or more requirements defined in this
specification.
2.2 Business Goals
The system shall provide a complete automated quantitative trading platform capable of:
Managing historical market data.
Discovering profitable trading strategies.
Validating strategies using statistical techniques.
Selecting the optimal strategy in real time.
Executing trades automatically.
Monitoring performance continuously.
Operating with minimal human intervention.

2.4 Functional Requirements
Every requirement receives a unique ID.
FR-001
Historical Candle Storage
Priority
Critical
Description
The system shall store historical OHLC candle data for every supported currency pair and timeframe.
Inputs
OANDA historical candles.
Outputs
Validated candle records stored in PostgreSQL.
Acceptance Criteria
No duplicate candles.
Missing candles detected.
Time ordering maintained.
FR-002

Priority

Description

2.6 Assumptions
OANDA API remains available.
PostgreSQL database remains accessible.
Historical data quality is sufficient for research.
Linux servers remain operational.
Internet connectivity is stable during live trading.
2.7 Constraints
Initial version limited to Forex.
Initial deployment limited to OANDA.
No high-frequency trading.
Only completed candles are used for signal generation.
Live trading disabled until strategy validation requirements are satisfied.
2.8 Success Criteria
The project will be considered successful when it can:
Store and maintain historical market data.
Discover profitable candidate strategies.
Validate strategies through multiple testing stages.
Select strategies automatically according to current market conditions.
Execute trades through OANDA with defined risk controls.
Produce detailed performance reports.
Operate continuously on in-house Linux servers.
