Architecture Decision AD-001
Raw Market Data is the Single Source of Truth
Decision
The QuantForge AI platform shall permanently store only raw market data and business data in
PostgreSQL.
Technical indicators shall not be permanently stored for every historical candle.
Instead, indicators will be calculated dynamically by the Python Research Engine and cached only when
there is a measurable performance benefit.
Rationale
Technical indicators are derived data, not primary data.
Examples include:
EMA
SMA
RSI
ATR
ADX
MACD
Bollinger Bands
SuperTrend
Donchian Channel
Stochastic
Since these values can always be recalculated from OHLCV data, permanently storing every indicator value
for every candle introduces unnecessary storage, maintenance, and complexity.

Benefits
Reduced Storage
The database stores only essential information.
Expected storage reduction:
70–90% compared to storing every indicator value.
Easier Maintenance
Adding a new indicator requires no database schema changes.
Only the calculation engine is updated.
Improved Flexibility
Changing an indicator formula or parameter does not require modifying historical database records.
The engine simply recalculates the values.
Better Performance
Historical research uses in-memory calculations.
Modern Python libraries such as:
NumPy
Polars
pandas
TA-Lib
can calculate indicators significantly faster than repeated database reads.

Intelligent Caching Strategy
QuantForge AI introduces three cache levels.
Level 1 — Research Cache
Purpose
Accelerate repeated historical research.
Storage
Parquet files.
Contains
Calculated indicators
Engineered features
Intermediate datasets
The cache can be regenerated at any time.
Level 2 — Live Cache
Purpose
Serve the live trading engine with minimal latency.
Technology
Redis
Contains only recent values required for active trading.
Examples
Latest EMA
Latest RSI
Latest ATR
Current market regime
Active strategy
This cache is temporary.

Architecture Principles
QuantForge AI follows these core principles.
Raw data is immutable.
Indicators are derived, not stored by default.
Features are generated dynamically.
Research is independent of live trading.
Every service has a single responsibility.
PostgreSQL is the single source of truth.
Redis is used only for transient live data.
Research caches are disposable and reproducible.
Every strategy must pass validation before production.
The platform must remain extensible to additional asset classes without architectural redesign.
