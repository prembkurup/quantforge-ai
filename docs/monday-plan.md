- Implement OANDA candle ingestion.
- Add candle data quality report.
- Implement Calculation Engine with indicator, statistical, volatility, and custom calculator modules.
- Implement Feature Engine and Feature Registry.
- Implement Market Regime Engine.
- Build Research Knowledge Base for validated findings, failed setups, and experiment evidence.
- Build Research Orchestrator to coordinate hypotheses, datasets, regimes, knowledge, experiment planning, job scheduling, result collection, and progress monitoring.
- Implement strategy plugin discovery.
- Implement experiment definition workflow.
- Build Constraint-Based Strategy Composer with validation, complexity scoring, diversity filtering, and decision traceability.
- Build Optimization Laboratory to find stable parameter regions and run Research Review Board gates.
- Build first template strategy plugin.
- Implement Backtesting Engine 2.0 with event-driven simulation, replay mode, time machine, and professional reports.
- Implement Strategy Validation Platform with Strategy Passport and Strategy Asset lifecycle.
- Implement Production Strategy Management Platform for catalog, registry, deployment, portfolio allocation, drift monitoring, and retirement.
- Implement Autonomous Research Validation for 100+ experiment lifecycle runs, Strategy Asset publishing, Knowledge Base updates, reports, and audit trails.
- Store experiment lineage, research run metrics, validation results, and analytics.
- Add Parquet research cache.
- Define live trading risk checks.
- Implement Live Trading Engine with event bus, Trade Decision Engine, execution manager, state store, recovery, and broker synchronization.
- Implement Shadow Trading and Paper Trading Platform with virtual exchange, paper portfolio, decision auditing, drift analytics, Digital Twin, and promotion review.
- Implement OANDA execution adapter dry-run mode.
- Add Linux server deployment plan.
- Implement Production Engineering and SRE controls for health, heartbeats, metrics, logs, traces, alerting, and recovery.
